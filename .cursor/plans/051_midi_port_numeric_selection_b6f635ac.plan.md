# План: выбор MIDI-портов по номеру в батнике

## Уточнение по фактическому состоянию
- Симптом: при выборе пункта `3` меню иногда происходит мгновенный возврат в главное меню.
- Причина: переход `if errorlevel 1 goto menu` в `:menu_set_input` срабатывает, когда `:select_port_by_number` не набирает ни одного порта (`PORT_COUNT=0`).
- Риск: парсинг в `:select_port_by_number` завязан на точные заголовки `Входные MIDI-порты:`/`Выходные MIDI-порты:`, что может ломаться из-за кодировки/локали/форматирования консоли.

## Что изменить
- В интерактивных пунктах `3` и `4` файла [D:/R_STUDIO/PRG/python/2026-05-23-midi-synt/configure_ports.bat](D:/R_STUDIO/PRG/python/2026-05-23-midi-synt/configure_ports.bat) заменить ввод «точного имени порта» на поток:
  - показать список портов,
  - запросить номер,
  - по номеру получить имя порта,
  - сохранить выбранный порт через существующий `main.py --set-config`.
- Добавить внутренние подпрограммы батника для переиспользуемого сценария выбора:
  - вывод нумерованного списка входных/выходных портов,
  - валидация, что введено число и оно в диапазоне,
  - извлечение имени порта по выбранному индексу.

## Опора на текущую логику
- Использовать существующую команду [D:/R_STUDIO/PRG/python/2026-05-23-midi-synt/main.py](D:/R_STUDIO/PRG/python/2026-05-23-midi-synt/main.py) `--set-config --input-port/--output-port`, чтобы не дублировать запись JSON и проверку валидности порта.
- Список портов брать из фактического вывода `main.py --list-ports` (тот же источник, что использует приложение), чтобы список в меню совпадал с реальными доступными портами.

## Детали реализации в bat
- Для пункта `3`:
  - сделать устойчивый сбор входных портов без жесткой зависимости от точного русского заголовка секции,
  - показать нумерацию пользователю,
  - принять номер, сопоставить с именем входного порта,
  - выполнить `main.py --set-config --input-port "<имя>"`.
- Для пункта `4`:
  - аналогично, но для выходных портов и `--output-port`, на той же устойчивой стратегии парсинга.
- Добавить обработку ошибок:
  - пустой список портов,
  - нечисловой ввод,
  - номер вне диапазона,
  - повторный запрос вместо аварийного выхода.

## Технический подход фикса парсинга
- В `configure_ports.bat` переписать извлечение строк портов так, чтобы:
  - опираться на шаблон строк портов (`число`.`пробел``имя`),
  - учитывать принадлежность к секции через более устойчивый признак (например, маркеры до/после пустой строки или fallback по порядку блоков),
  - не зависеть от точного совпадения кириллических заголовков.
- Сохранить текущий UX:
  - выбор по номеру,
  - цикл повторного запроса при ошибке,
  - возврат в меню только при реальном отсутствии портов или ошибке вызова `main.py`.

  - пункт `5`: последовательный выбор обоих индексов сохраняет оба порта,
