- По `*` в live-цикле будет toggle текущего `program` в избранных (добавить/удалить).
- По `PgUp/PgDown` будет переключение на предыдущий/следующий избранный; если текущий `program` не в списке, переход к ближайшему по номеру; если список пуст — лог `Нет избранных, добавьте в избранные через *`.

## Поведение клавиш
- `*`:
  - Берём текущий активный канал через `ProgramController` и его текущий `program`.
  - Если `program` уже в избранных — удаляем, иначе добавляем.
  - Сохраняем JSON сразу после изменения.
- `PgDown`:
  - Следующий избранный (по возрастанию, циклически).
- `PgUp`:
  - Предыдущий избранный (по убыванию, циклически).
- Если текущий `program` не в избранном:
  - Выбор ближайшего по номеру в направлении клавиши.

## Формат JSON
- Файл: `midi_favorites.json` рядом с `main.py`.
- Минимальный формат:
  - `{ "schema_version": 1, "programs": [0, 48, 73] }`
- Правила устойчивости:
  - Нет файла → пустой набор.
  - Битый JSON или невалидные значения → предупреждение + игнор некорректных записей, без падения приложения.
  - При сохранении писать отсортированный уникальный список программ.
