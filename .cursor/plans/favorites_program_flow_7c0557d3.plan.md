## Поведение клавиш
- `*`:
  - Берём текущий активный канал через `ProgramController` и его текущий `program`.
  - Если `program` уже в избранных — удаляем, иначе добавляем в конец списка.
  - Сохраняем JSON сразу после изменения (перезапись файла).
- `PgDown`:
  - Переход к предыдущему элементу списка избранных (циклически): пример `12 -> 23`, `1 -> 125`.
- `PgUp`:
  - Переход к следующему элементу списка избранных (циклически).
- База навигации:
  - Если есть `last_favorite_index`, шагаем от него, даже если текущий `program` сейчас вне избранных.
  - Если `last_favorite_index` ещё нет, пробуем привязаться к текущему `program` (если он в избранных), иначе стартуем с ближайшей позиции по направлению шага.
- Если избранные пустые:
  - Пишем в лог: `Нет избранных, добавьте в избранные через *`.
- `p/P/з/З`:
  - Печать списка избранных программ в текущем порядке хранения.
- `h/H/р/Р`:
  - Печать списка всех быстрых клавиш: `+`, `-`, `*`, `PgUp`, `PgDown`, `p/P/з/З`, `h/H/р/Р`, `Ctrl+C`.

## Формат JSON
- Файл: `midi_favorites.json` рядом с `main.py`.
- Минимальный формат:
  - `{ "schema_version": 1, "programs": [1, 23, 12, 125, 7] }`
- Правила устойчивости:
  - Нет файла → пустой список.
  - Битый JSON или невалидные значения → предупреждение + игнор некорректных записей, без падения приложения.
  - При сохранении сохранять уникальные значения в текущем порядке добавления (без сортировки).
  - На любое изменение списка (`*`) выполнять полную перезапись файла.
