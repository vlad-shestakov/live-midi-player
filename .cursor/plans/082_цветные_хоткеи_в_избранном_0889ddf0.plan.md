# План: Цветные горячие клавиши в списке избранного

## Цель
Сделать вывод `Избранные программы` более удобным: возле каждой позиции показать соответствующую горячую клавишу (`F1..F10`, `Shift-F1..Shift-F10`) и добавить внизу краткие подсказки по действиям `*`, `PgUp`, `PgDown` в цвете.

## Изменения в коде
- Обновить `print_favorites()` в [d:\R_STUDIO\PRG\python\2026-05-23-midi-synt\main.py](d:\R_STUDIO\PRG\python\2026-05-23-midi-synt\main.py):
  - Для каждого элемента списка выводить формат `N. <hotkey> - <program_with_name>`.
  - Для позиций `1..10` использовать метки `F1..F10`.
  - Для позиций `11..20` использовать метки `Shift-F1..Shift-F10` (включая `19 -> Shift-F9`, `20 -> Shift-F10`).
  - Метку хоткея окрашивать тем же цветом, что и прочие шорткаты (`ANSI_BLUE` через `colorize`).
  - Если элементов больше 20, для позиций `21+` выводить остаток строго без хоткея: `N. <program_with_name>`.
- В конце `print_favorites()` после списка добавить строки-подсказки:
  - `*       : Добавить/удалить текущую программу в избранном`
  - `PgUp    : Следующая избранная программа (по списку)`
  - `PgDown  : Предыдущая избранная программа (по списку)`
  - Имена клавиш (`*`, `PgUp`, `PgDown`) окрашивать в `ANSI_BLUE`.
