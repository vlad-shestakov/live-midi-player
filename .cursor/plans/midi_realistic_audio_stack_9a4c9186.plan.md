# План для MIDI-клавиатуры с максимально убедительным звуком

## Цель
Слушать MIDI-клавиатуру в реальном времени и воспроизводить звук с максимально реалистичным тембром и минимальной задержкой.

## Рекомендуемый стек (по приоритету)
- `mido` + `python-rtmidi` для стабильного MIDI-ввода в реальном времени.
- Внешний VST-хост/DAW (например, Reaper/Cantabile) + качественный VST-инструмент (Pianoteq, Kontakt-библиотеки, Keyscape и т.д.) для наилучшего реализма.
- Альтернатива «больше в Python»: `pyfluidsynth` + качественный SoundFont (`.sf2`) или SFZ-библиотеки.
- `pyo` — если нужен именно синтез/DSP внутри Python (менее приоритетно для реалистичного акустического звука).

## Практическая архитектура
- Python-процесс принимает события Note On/Off и CC с MIDI-клавиатуры через `python-rtmidi`.
- События отправляются в звуковой движок:
  - Либо в DAW/VSTi через виртуальный MIDI-порт (предпочтительно по качеству).
  - Либо в FluidSynth при необходимости более автономного Python-решения.

## Критичные параметры для «живого» ощущения
- Драйвер: ASIO (или WASAPI exclusive).
- Буфер: 64-128 сэмплов.
- Sample rate: 48 kHz.
- Минимальная логика в MIDI callback, чтобы не увеличивать latency/jitter.

## Что выбрать по умолчанию
- Если приоритет №1 — реализм звучания: `python-rtmidi` + DAW/VSTi.
- Если приоритет — простота разворачивания в Python: `python-rtmidi` + `pyfluidsynth` + хороший SoundFont.
